# DevVerse - Into the Scrape-Verse Hackathon Project

DevVerse is an AI-powered Developer Intelligence Hub built for the Bright Data *Into the Scrape-Verse* hackathon.

## Features
- **Scraper Studio Integration**: Custom JavaScript collectors for Bright Data to scrape documentation and GitHub tech trends.
- **AI Self-Healing Sentinel**: Uses Google Gemini to automatically repair broken JSON schemas when documentation websites change their HTML structure.
- **Agent Skill Generator**: Distills raw documentation into markdown-based Skills for autonomous coding agents.
- **Content Studio**: Generates blogs, YouTube scripts, and newsletters based on ingested tech trends.
- **Telemetry Hub**: Live tracking of Scraper Studio metrics and Self-Healing events.
